# W2 Grid30k Second-Pass Grid30k Run

## Goal

Run a grid-only second pass:

1. Use the current best merged xz10 grid 30k model as pretrain.
2. Repartition with the same xz10 grid geometry.
3. Train grid blocks for another 30k iterations.
4. Strict-merge iteration 30000, then render and evaluate
   `manual_passage_review_15000`.

This tests whether repeating the CityGaussian-style xz10 grid pass improves or
stabilizes the current best grid candidate.

Gaussians, which likely explains the lower render cost but also the quality
drop. Keep
`w2_filtered_manual_passage_no415_manual_units30k_to_citygs_xz10_30000` as the
current best candidate.
